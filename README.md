# korean-handwriting-rec · 한국어 손글씨 OCR

**손글씨도 읽는 PP-OCRv5.**

한국어 | [English](README.en.md) · [모델 다운로드](https://huggingface.co/Rebeccaaaaaaaa/korean-handwriting-rec)

korean-handwriting-rec은 PP-OCRv5에 한국어 손글씨를 더 가르친 OCR 인식 모델입니다. AI Hub 손글씨·공문서 데이터로 추가 학습했으며, 약 15MB의 ONNX 모델을 CPU에서 실행할 수 있습니다.

- **손으로 쓴 기호 39.7% → 97.3%**: `₩8,470,000`, `143.1m²`, `2026.7.1~2028.6.30`, `12+30=42`, `〃`처럼 사람이 서류에 손으로 쓰는 기호를 읽습니다.
- **손글씨 금액·날짜의 쉼표·점 56.8% → 96.9%**: `7,278.37`, `(679,000)`처럼 숫자와 기호가 섞인 손글씨를 읽습니다.
- **손글씨 단어 67.2% → 95.9%**: 학습에 쓰지 않은 2만 단어에서 기존 모델과 비교했습니다.
- **흘림체 문장 오류율 30.0% → 6.3%**

RapidOCR에서는 인식 모델과 글자 사전 경로를 지정해 연결합니다.

## 빠른 시작

저장소를 받은 뒤 RapidOCR 3.x와 ONNX Runtime을 설치합니다.

```bash
git clone https://github.com/VerifiedIdiot/korean-handwriting-rec.git
cd korean-handwriting-rec
python -m pip install "rapidocr>=3,<4" onnxruntime
```

저장소 루트에서 실행합니다. `scan.png`는 읽을 이미지의 경로로 바꿉니다.

```python
from rapidocr import RapidOCR

engine = RapidOCR(params={
    "Rec.model_path": "model/rec_korean_hw.onnx",
    "Rec.rec_keys_path": "model/ppocrv5_korean_dict.txt",
})
result = engine("scan.png", use_cls=False)
print(result.txts)
```

이 예제는 정방향 이미지를 기준으로 자동 방향 분류를 끕니다. 이 저장소는 **글자 인식 모델**을 제공하며, 검출 모델은 RapidOCR이 별도로 사용합니다. 첫 실행에는 검출 모델을 내려받기 위한 인터넷 연결이 필요할 수 있습니다.

## 자주 묻는 질문

### 기존 PP-OCRv5 대신 쓸 수 있나요?

RapidOCR에서는 위 예시처럼 인식 모델과 사전 경로를 지정합니다. 글자 검출 모델은 기존 것을 사용할 수 있습니다. 다른 OCR 도구에 연결할 때는 해당 도구의 입력 전처리와 출력 해석 방식을 확인해야 합니다.

### GPU나 외부 API가 필요한가요?

ONNX Runtime으로 CPU에서 실행할 수 있으며, 인식할 이미지를 외부 OCR API에 보내지 않습니다. 오프라인에서 쓰려면 패키지와 사용할 검출·인식 모델을 미리 준비해야 합니다. 방향 분류를 사용한다면 분류 모델도 필요합니다.

### 인쇄된 글자도 읽나요?

공문서 인쇄 글자를 함께 학습해, 학습에 없던 정부 서식 5종의 인쇄 글자에서 99.2%를 읽습니다.

### 손으로 쓴 금액과 날짜도 읽나요?

네. 쉼표·점·하이픈·빗금·괄호와 원 기호(₩)·같음표(〃)·퍼센트·더하기·등호·우물정(#)·위첨자(m²)·물결(~)이 섞인 손글씨 숫자를 따로 학습했습니다. 손글씨 금액·날짜·전화번호 3천 줄에서 96.9%, 손으로 쓴 기호가 든 3천 줄에서 97.3%를 읽습니다.

### 글자 사전이 기존과 같나요?

기존 PP-OCRv5 한국어 사전 11,945자에 사람이 서류에 손으로 자주 쓰는 `₩`와 `〃` 두 글자를 끝에 더했습니다(11,947자). 모델과 사전 파일을 함께 바꿔 쓰면 됩니다.

### PDF의 표나 문서 구조도 추출하나요?

아니요. 이 모델은 글자 영역의 텍스트를 읽습니다. PDF를 이미지로 바꾸거나 표·레이아웃을 분석하는 기능은 포함하지 않습니다.

## 학습 방법

PaddleOCR의 사전학습 모델을 PyTorch로 옮겨 네 단계로 추가 학습했습니다. 글자 사전은 기존 PP-OCRv5 한국어 사전에 `₩`·`〃`를 더한 것입니다.

1. **손글씨** (Mac GPU): 손글씨 386만 단어를 1 epoch 학습했습니다. 샘플의 20%는 같은 단어를 인쇄체로 렌더링해 섞었습니다.
2. **공문서 인쇄** (Mac GPU): 정부 서식 인쇄 글자 42만 단어와 필기체 30만 단어에 1단계 손글씨 120만 단어를 섞어 이어서 학습했습니다.
3. **숫자·기호와 다양한 글씨** (NVIDIA DGX Spark): 필자마다 손글씨 숫자를 한 자씩 모아 쉼표·점·빗금·괄호·원 기호와 함께 금액·날짜·전화번호 띠 40만 줄을 만들고, 초·중학생 손글씨 58만 단어와 앞 단계 데이터를 섞어 190만 장을 이어서 학습했습니다.
4. **손으로 쓰는 기호** (NVIDIA DGX Spark): 사전에 `₩`·`〃`를 더해 출력층을 넓히고, 이율·면적·기간·계산·번호·같음표를 손글씨 숫자와 함께 쓴 띠 15만 줄을 앞 단계 데이터와 섞어 50만 장을 이어서 학습했습니다.
